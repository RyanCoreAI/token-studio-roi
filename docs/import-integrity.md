# ccusage 导入与本机服务边界

ccusage 的 daily、project-daily、weekly、monthly、blocks 和 session 报告都是汇总快照，不是新增消费流水。相同设备、来源、会话、模型的 session 快照重导会更新既有数量；不同设备和中文项目路径使用完整 UTF-8 内容生成确定性身份，不再通过删除字符或截断来区分。

导入在一个 SQLite 事务中更新事件并重算受影响会话和日汇总。同日分批导入不同会话、同会话的不同模型、重复导入、累计会话更新时间变化都必须保持对账。同一设备/来源/日期的不同报告形态可能包含同一份用量，因此重叠导入会被拒绝；先核对原始报告，不要混用日报与会话报表来累计同一段消费。

已有旧版导入记录不会自动迁移或删除。一个实际身份完全匹配的旧 event ID 会被复用。若有损项目 ID 已经落库，或同一会话/模型存在多份旧快照而无法确认应覆盖哪份，导入会在任何写入前拒绝并提示检查历史；它不会通过生成新 ID 悄悄保留双份用量。导入无法恢复此前已被身份碰撞覆盖或合并的原始记录，需要保留并核对源报告。

模型 breakdown 使用各模型自己的 token 字段，不继承父汇总的数量。提供 totalTokens 时，它必须等于已提供 token 分桶之和。未知价格仍保持未定价，费用是配置的官方价格折算值，不代表账单或订阅实付。

普通 Dashboard API 同时验证连接地址、Host 和 Origin。仅实际 loopback IP 或完整的 localhost 可作为本机身份，类似 127.example.com 的域名不会被信任；缺少 Origin 的本机命令行 GET 仍可使用。显式远程 ingest 继续需要 Bearer token，不能借此开放 Dashboard。静态目录和读取失败会返回请求错误，不终止本地服务。
